<h2 id="第一天-长春-2023-08-09"> 第一天-长春 (2023-08-09)</h2> <ul>
<li>今天刚刚到机场，曹雪的四姨父来接我们了，这次旅行，<code>曹雪、大舅-许建新，妈妈-许建英</code>，我们从无锡出发，跨越1800km</li> <li>的路程，来到了长春，然后匆匆忙忙的到了宾馆，安排了房间，外面溜达了一会，就去了吃饭的地方。</li> <li>哎呀妈呀，东北人太tm的热情了，我是真的没有想到，单纯的一顿饭，在东北能有那么多的火花。</li> <li>认识了曹雪的<code>大姨夫一家，三姨夫一家</code>，太热情了，他们每个人提酒之前，都会说一句祝福的话语，太热闹了，东北菜</li> <li>非常的好吃，曹雪也哭了，因为好久，有4年没回来了，真的不容易。</li> <li>对了，大舅还喝醉了，<code>岁月催人老</code>，年纪大了，酒量大不如前。</li>
</ul> <h2 id="第二天-东丰县-2023-08-10"> 第二天-东丰县 (2023-08-10)</h2> <ul>
<li>大姨夫一家，请我们吃了当地的早餐，吃了豆腐脑，当地特色的酱料，虽然和南方的味道不一样，吃起来确实有不一样的感觉</li> <li>后面又带我们去参观了他们的家，看的出来是个很有实力的家庭，由于工作原因，后面东风县，我们大姨父一家就没有作陪。</li> <li>之后来了东丰县，四姨还特意坐了公交车，因为车里坐不下那么多人，真的辛苦她了，我们驱车2-3个小时后，到了东丰县，</li> <li>之后见到了<code>许涵翊,三姨</code>,许久不见，格外亲切。当天晚上吃了啥？，有点不记得了，反正吃爽了，也喝爽了。好像是烤全羊？</li> <li>不记得了，还见了曹雪的<code>老姨</code>， 对了，他们东北对<code>老姨</code>的称呼是最小的意思，曹雪的奶奶97岁了，就是耳朵不太好使，身体看上去也不错，希望能活到100岁。</li> <li>反正还是吃好，喝好，玩好。</li>
</ul> <h2 id="第三天-海龙湖-2023-08-11"> 第三天-海龙湖 (2023-08-11)</h2> <h3 id="曹雪与姑姑的离别"> 曹雪与姑姑的离别</h3> <ul>
<li>明显能感受到大舅是真的老了，睡眠不足，早早的就起来，而且一直敲腿，貌似腿不太好使了。</li> <li>后面我们陪曹雪来到了他姑姑一家，因为曹雪父亲走了快十年了，跟姑姑比较亲，已经很多年没见了，去了简单说了几句话</li> <li>唠了会嗑，还有，东北人还喜欢拍照，这根我们所认识的南方人完全不一样，我给他们一起拍了张合照，然后我们就匆匆走了</li> <li>因为一会还有赶路行程，在离别时刻，突然看到曹雪哭了，然后姑姑也哭了，因为嫁在远方，所属不易，今后可能见不到几次面了，</li> <li>离别的感受确实不好，我们一行人离开，走在路上，曹雪回过头，看着姑姑，还站在原地，目送前方，又留下了泪水。</li>
</ul> <h3 id="海龙湖"> 海龙湖</h3> <p><strong><code>中午</code></strong></p> <ul>
<li>我们来到了海龙湖，中午到<code>梅龙镇</code>,吃了一顿，我觉得，那是我吃过最好吃的东北菜，一共6个菜，够我们10个人吃，真的</li> <li>太猛了，在南方不可能发生这种事，最爱吃香菜肉丝，下面铺垫的是辣椒，写着写着，饿了。</li>
</ul> <p><strong><code>下午</code></strong></p> <ul>
<li>我们到了海龙湖，天气26度左右，不过还是有点热，我看了下，是个湖，然后有人造沙滩，人不少。我们溜达了一圈，看了</li> <li>不少风景，感觉很惬意，还有鸭子，然后，东北荷花很少，东北娘们们又开始疯狂的拍照了。我们也照了几张，下面是图片
..待上传.</li> <li>我们后来又看到了飞艇，跟许涵翊坐了，太刺激啦，不过有点贵，好像130一人？ 许涵翊真是的胆小鬼，上去之前怕死了。我上去之后</li> <li>就感觉，真他吗后悔上来，又是失重感，尴尬的跟司机说，开慢点。。后面慢慢适应了，然后说了句<code>我cnm的生活</code>，后面也尝试开了</li> <li>会飞艇，跟开电瓶车差不多，从来没有玩过这个，感觉还挺刺激的。开心捏。</li> <li>最后我们去了网红街<code>梅河镇</code>,看到了花海，逛了古镇商业街，谢谢四姨请我们吃东北老冰棒，太爽啦。美中不足是期间大家被</li> <li>淋雨了。</li>
</ul> <p><strong><code>晚上</code></strong></p> <ul>
<li>我们驱车回到了东丰镇，说要吃当地的烧烤，吃的很热闹，但是对我来说，味道太重了，感觉不如上次在长春吃的，但是熬不住他们的热情，</li> <li>晚上又喝了不少酒。真的十分感谢他们。</li>
</ul> <h2 id="第四天-长白山脚下-2023-08-12"> 第四天-长白山脚下 (2023-08-12)</h2> <ul>
<li>我们驱车200多km，来到了长白山脚下，泡了酒店的温泉，跟许涵翊玩了会水。</li> <li>当晚，二姨家请吃饭，饭菜一般，感觉不是很新鲜，在一个装修的老宅下拍了许多照片。</li>
</ul> <h2 id="第五天-长白山之行-2023-08-13"> 第五天-长白山之行 (2023-08-13)</h2> <ul>
<li>与我之前逛的山差不多，可惜天空不作美，没有看到天池。</li> <li>不过我们看到了瀑布，小天池，天外飞池，绿渊谭，虽然不是那么令人惊讶，但是看了也是心旷神怡。</li> <li>对了，我们还吃了天池的水煮蛋，许涵翊这货吃了6个（至少），真的能吃。爬山也看出来大舅身体不如以前了。我的母亲也老啦。</li> <li>今天晚上，我请了他们吃了晚饭，希望时间过得慢些，小孩慢慢长大，老人也慢慢变老，生活越来越好。保持这样的欢乐日子就行。</li>
</ul> <h2 id="第六天-延边之旅-2023-08-14"> 第六天-延边之旅 (2023-08-14)</h2> <h3 id="初识延边"> <code>初识延边</code>
</h3> <ul>
<li>延边跟张家港市(我老家)一样，是个县级市，面积是张家港的1.5倍，但是人口确不足张家港一半，因为是旅游城市。</li> <li>我们来到了延边，感觉来到了韩国，牌匾都是汉语，其实这里是朝鲜族聚集地，他们长得真的跟电视上一样，就是韩国人的样子，大多数</li> <li>都是韩国人的样子，还住了非常好的宾馆，免费洗浴，晚上还跟许涵翊一起泡了澡，擦了背，没错，又是喝多了去泡的，晕晕的，搞不过许涵翊。</li>
</ul> <h3 id="恐龙王国乐园"> <code>恐龙王国乐园</code>
</h3> <ul>
<li>
<code>曹雪、许涵翊、杨天晴，我</code>，我们一起去了恐龙王国，对了，许涵翊是曹雪的儿子，杨天晴和许涵翊是两个5年级的孩子，但是天晴已经是165的小学生了。。</li> <li>跟我差不多高了，她说话太温柔了，就跟她的名字一样，让我想起了<code>《爱在雨过天晴时》</code>(这是台湾的翻译，国内叫<code>恋如雨止</code>)这个动漫, 能感觉出来，她将来</li> <li>是个大美女，希望她能收获甜甜的爱情。</li>
</ul> <p><strong><code>室内游玩</code></strong></p> <ul>
<li>我们来到了恐龙王国，门票有点贵，300多一人，游玩的人不是很多，不过项目很好玩，我们一起玩了海盗船，许涵翊和曹雪，吓死了，曹雪一直在叫，而许涵翊</li> <li>也是怕的要死，头直接窝在下面，因为我之前做过，所以我知道有点吓人，但是还是犯贱一样的上去了，我们还坐了两次，其中有一人没有再次坐。</li> <li>我们最后还玩了个5d项目，跟迪士尼的飞跃地平线一样，挺好看的，但是我感觉做的不如无锡的飞跃江苏。</li>
</ul> <p><strong><code>室外游玩</code></strong></p> <ul>
<li>室外，我们玩了过山车，我以为会很吓人，但是其实还好，因为很短，感觉不到1分钟就结束了，就只有向下冲刺的时候吓到了，天晴是一点不怕，许涵翊胆子</li> <li>很小，但是还是去坐了，曹雪后面尝试坐了一次。</li> <li>这次游玩真的很开心，虽然时不时还会想起她，每次都想，如果她在多好，但是可能已经回不去了。</li>
</ul> <h3 id="晚饭"> <code>晚饭</code>
</h3> <ul>
<li>由于我们玩的很晚，晚饭延迟了一会，今天是四姨请吃饭，从我第一次见到四姨开始，我真的很亲切，虽然她一直劝酒，她长得也很像我姑姑，性格就像是外放</li> <li>型的姑姑，所以每次跟她喝酒，很<code>得劲</code>。对了，吃的饭叫<code>元奶奶包饭</code>, 味道不错，尤其是她家的包饭，吃了不少。</li>
</ul> <h2 id="最后一天-2023-08-15-20-28-49"> <code>最后一天</code> 2023-08-15 20:28:49</h2> <ul>
<li>我要现行离开了，中午，二姐&amp;姐夫请我们吃饭，烤鱼，味道太重口啦，有些许辣，不过他们貌似挺喜欢，今天没有喝酒，感觉喝的不<code>得劲</code>，不过我要走了，喝</li> <li>不了，离别总是伤感的。</li> <li>我现在在飞机上，哈哈哈，写下了这篇文章.</li>
</ul> <h3 id="离别"> 离别</h3> <ul><li>最后，四姨父送了我最后一程，握了我的手，有空一定要来张家港玩，好好的尝尝江南美味。</li></ul> <h3 id="小事"> 小事</h3> <ul>
<li>许涵翊在游乐园丢了一次, 被她妈妈暴揍。</li> <li>我在车上偷偷放屁了，三姨问<code>谁放的？</code>，巨尴尬 哈哈</li> <li>提到她，我又流下了眼泪。真的对不起。</li> <li>妈妈老了哇。求时间过的慢些。</li>
